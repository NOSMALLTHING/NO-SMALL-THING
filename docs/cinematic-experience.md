# Cinematic experience refinement

基于既有 Next.js/React/Motion 版本增量开发，保留全部已确认文案、服务、Concept Projects 与联系流程。没有增加 GSAP/Lenis 或第二套滚动引擎。参考 [Production Portugal](https://productionportugal.com/) 的视觉质量与展示节奏，未复制其源代码、文案、影像或特色转场。

## 品牌素材

用户提供的三个 PNG 均按原文件复制至 public/brand/，没有重绘 Logo。白色字标本身具有透明 Alpha，浅色预览中的“空白”并非空图片。导航使用它的响应式无损 WebP，N 符号提供 384/768px WebP；原文件及初版完整 Logo 均保留。尺寸优化脚本可重新生成资源。

## 降级与工程边界

- 初始 HTML 内容可见，不需要 JavaScript 才能阅读；客户端就绪后才启用滚动增强。
- 手机/平板没有桌面额外停留区间，Mars 主标语、飞船与地平线保持安全画幅。
- reduced-motion 关闭固定开场、相机位移、文字遮罩、菜单动画及页面转场；业务内容正常展示。
- 不接管滚轮，不强制滚动，不插入等待屏；键盘焦点进入项目时跳过图片遮罩。
- Motion 管理滚动订阅；设备媒体查询监听在卸载时移除。无需常驻 RAF 或额外滚动控制器。
- 正式域名仍未确定；不配置或发布虚构域名。没有公开部署。

## 进一步的参与式动效

研究了用户指定的 [Clients 页面](https://productionportugal.com/clients)，实际观察并体验其拖拽反馈。借鉴“访客参与画面运动”的原则；没有复刻弯曲客户 Logo 墙或使用任何未经提供的客户标志。

- Selected Work 改为可拖拽的横向电影展映带。仅两个真实标记的概念研究，提供惯性预测与吸附、前后按钮、进度指示、方向键/Home/End，以及键盘聚焦项目后自动显露该项目。
- 拖拽距离阈值 7px，防止拖动被误认作打开案例；正常点击与键盘 Enter 保持可用。手机使用浏览器原生横向滑动；不阻止垂直浏览。
- 展示图片与 N 符号通过弹簧缓动跟随鼠标；Mars 首屏只有小角度镜头反馈，保持文字和主体构图。没有新增三维资产、粒子、光效或第三方引擎。
- 大标题以字形遮罩和转动构成波次；品牌故事随滚动从可读灰色逐词变为暖白。标题保留完整辅助技术名称，叙述按原文正常朗读。
- Approach 细线跟随滚动推进；桌面页脚从 Contact 后方逐步揭示。手机和 reduced-motion 使用正常页面流。
- 无脚本时保留全部内容、原生横向滚动与滚动条，交互按钮禁用并提供操作提示。减少动态效果关闭空间和文字动态，并使用即时切换；监听、ResizeObserver 和惯性动画在卸载时清理。

浏览器验证了鼠标拖拽吸附、不误导航、前后按钮、End 键切换、Enter 打开案例。1440/768/390/320px 无页面横向溢出；390px 与 320px 的作品及 Contact 标题已目视检查。截图：artifacts/immersive-work-reel.png、immersive-work-mobile.png。未把桌面尺寸模拟等同于实体触屏测试。

最终构建与 TypeScript 检查通过；4 项表单测试通过；最终静态验证覆盖 9 个页面、35 个资源请求，全部通过。首页浏览器未捕获运行时错误。
